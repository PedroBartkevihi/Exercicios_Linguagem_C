# Exercícios em C

Este repositório reúne exercícios desenvolvidos durante meus estudos de programação em linguagem C.

O objetivo é praticar os principais fundamentos da linguagem, registrar minha evolução e manter um histórico organizado das listas resolvidas.

## Conteúdos estudados

### Lista 1 — Variáveis, entrada e saída, expressões aritméticas e conversão de tipo

Exercícios focados em:

- Declaração de variáveis
- Entrada de dados com `scanf`
- Saída de dados com `printf`
- Operações aritméticas
- Conversão de tipos
- Divisão inteira e resto da divisão
- Uso de constantes simples
- Cálculos matemáticos básicos

### Lista 2 — Expressões relacionais e lógicas, estruturas de seleção e funções matemáticas

Exercícios focados em:

- Operadores relacionais
- Operadores lógicos
- Estruturas `if`, `else if` e `else`
- Estrutura `switch`
- Validação simples de entrada
- Uso da biblioteca `math.h`
- Funções como `sqrt()` e `pow()`
- Classificação por faixas e tabelas de decisão

### Lista 3 — Estruturas de repetição, contadores, acumuladores e laços aninhados

Exercícios focados em:

- Estruturas de repetição `for`, `while` e `do while`
- Contadores e acumuladores
- Incremento e decremento
- Impressão de sequências numéricas
- Cálculo de somatórios e médias
- Validação de entradas em laços
- Uso de laços aninhados
- Impressão de figuras com asteriscos
- Tabuada em formato tabular
- Séries matemáticas
- Progressão aritmética e progressão geométrica
- Sequência de Fibonacci
- Verificação de números primos
- Verificação de números perfeitos
- Verificação de números capicuas
- Menor e maior valor em uma sequência
- Cálculo de percentual
- Menus com repetição e `switch`
- Cálculo do dia da semana a partir de uma data

## Como compilar

Para compilar um exercício em C com `gcc`:

`gcc Lista1/Exercicio01.c -o Exercicio01.exe`

Exemplo para a Lista 2:

`gcc Lista2/Exercicio01.c -o Exercicio01.exe`

Exemplo para a Lista 3:

`gcc Lista3/Exercicio01.c -o Exercicio01.exe`

Para exercícios que utilizam funções matemáticas da biblioteca `math.h`, pode ser necessário usar:

`gcc Lista2/Exercicio01.c -o Exercicio01.exe -lm`

ou:

`gcc Lista3/Exercicio01.c -o Exercicio01.exe -lm`

## Objetivo

Organizar meus estudos, praticar lógica de programação em C e registrar minha evolução como programador.

Este repositório também serve como um histórico do meu aprendizado, mostrando a evolução desde exercícios básicos de entrada e saída até problemas envolvendo condições, repetições, validações, séries matemáticas e estruturas mais elaboradas.
